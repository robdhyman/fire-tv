# Lowlight: generated art prompts

A Coming Soon movie, invented for [Style lock](https://github.com/robdhyman/fire-tv/issues/33) on 3 Nov 2026; [Coming Soon movies](https://github.com/robdhyman/fire-tv/issues/35) adds it to the catalogue. This file is the only prompt record for the movie.

- **Catalogue entry**: id `lowlight`, brand `syfy` (SYFY), genre `sci-fi`, poster `lowlight/poster.jpg`.
- **Logline**: A night-shift crew on an orbital mirror finds the sun has been dimming for a year, and that someone on the ground has been paying to keep it quiet.
- **Model**: Nano Banana 2.1 (Weave model `bebebed5-50c1-4701-98b3-86929db21585`, fal `fal-ai/nano-banana-2/edit`), no reference image (a movie has no hero to edit from).
- **House-style suffix**: `HS-1` with this movie's palette: graphite, gunmetal blue, sodium orange and frost white; accent: dying-sun gold. A poster with its title in the image drops "No on-screen text, no lettering," from the suffix.
- **Title**: set in the image, as Rob chose on 3 Nov 2026 (the app does not set it over the poster). Check the spelling on every take.
- **Converted** with `scripts/convert-generated-art.mjs` to 1006x1500, JPEG under 400 KB.
